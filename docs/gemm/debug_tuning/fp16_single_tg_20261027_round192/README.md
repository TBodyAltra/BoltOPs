在隔离的Bolt worktree188中给MLS kernel增加默认0的constexpr `REBASE_MLS_TILE`。mask1/2分别将A的M偏移、B的N偏移提前折入基址，mask3同时处理两者，并将剩余shape同步改为M-m0/N-n0，保留原来的每一个地址和边界。K循环、累加次序、full-BK128运输、TG排布和C掩码保持原契约；没有固定运行时M/N。该实验仅允许NoWASP/MIXED_OPERAND=0。Triton121与native95保持冻结；没有扩大寄存器或LDS上限。

本轮范围为 **256×128×128 TT、NoWASP/NoWDRA、8 warps、stage1、Bfirst、MMA_K_SPLIT4、fragment MLS、EPTrue、LDS65536字节**。rebase1/2/3 × generic/GROUP1 × UF2/4共12项，全部实际ISA不同于对照及本轮其他项。默认0两个CPU及PMD对照精确通过。

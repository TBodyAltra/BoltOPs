本批追加 66 个候选，性能地图累计 8807 行，503 条性能最佳选择保持不变。round216：28 个候选、115 个模型点；round220：6 个候选、31 个模型点；round225：32 个候选、135 个模型点。没有性能晋级。

另对六个主 WDRA 配方降低初始 VGPR reservation，按初测和唯一一次独立复测均保留原最佳至少 98% 吞吐、稳态残差不超过 2%、scratch/VGPR/SGPR spill 全为零的资源策略筛选。round227 使用 24 个模型点完成复测。它们是资源备选，不替换性能最佳，不代表 consumer 所需寄存器减少或多 TG 占用率提升。

原始跨 worktree 全 ASM 字节检查因调试路径、调试字符串偏移不同而失败，脚本与失败日志完整保留。随后检查全部 18 对程序：将缓存 HSACO 的同伴 ASM 与实测 ASM 逐字节绑定，证明所有 allocated ELF 段（包含 AMDGPU metadata note、text、rodata）和全部非调试段完全相同；完整 ASM 仅允许精确根路径替换及 `.asciz` debug offset 注释归一化。没有因该差异重跑 GPU 数据或宣称原始 ASM 字节相同。

每个候选初测含 16/32/64 循环校准和 4TG 非原点、M/N 边缘及 K/BK=17 正确性检查。性能点为单 TG，完整 GOLD seed29/scale1、FP16 输入、FP32 累加、FP16 输出，atol=rtol=1e-3；动态 MMOP/逻辑工作量=1。复测为独立进程、独立测量 context。128³ 持续暂缓。源码使用隔离的 Bolt197 和 Triton209 worktree，固定 native209，完整源码补丁与增量 native 构建 provenance 见前一批 round213 文档及 round226 补充。
